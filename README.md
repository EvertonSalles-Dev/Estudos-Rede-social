# 🌐 Estudos - Rede Social

Um projeto de estudos focado no desenvolvimento de uma interface moderna para uma rede social utilizando apenas **HTML5, CSS3 e JavaScript**.

> ⚠️ Este projeto é apenas um protótipo visual e está em desenvolvimento. O objetivo é estudar conceitos de UI/UX, organização de código e criação de interfaces responsivas antes da implementação de um backend.

---

## 🚀 Objetivo

Desenvolver uma rede social moderna com foco em:

- Interface elegante e intuitiva
- Experiência do usuário (UX)
- Design responsivo
- Componentes reutilizáveis
- Organização de código
- Animações suaves
- Estrutura preparada para futuras integrações com backend
